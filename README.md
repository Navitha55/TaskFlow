# TaskFlow

TaskFlow is a productivity-focused task management web application designed to help users organize their daily activities, categorize tasks, stay on schedule, and improve productivity.

The project began as a simple To-Do List landing page and is being developed into a complete Django-based task management system. The landing page introduces the purpose and key features of TaskFlow while providing clear navigation to user registration and login.

The application is designed around individual user accounts, allowing users to securely manage their own tasks. Planned functionality includes creating, viewing, editing, deleting, categorizing, and completing tasks, along with reminders for important activities and deadlines.

### Key Features

* 📝 Create and manage personal tasks
* 📂 Categorize tasks based on priority or purpose
* ✅ Mark tasks as completed
* ✏️ Edit existing tasks
* 🗑️ Delete tasks
* ⏰ Manage important deadlines and reminders
* 🔐 User registration and login
* 👤 Individual task management for each authenticated user
* 🌙 Light and dark theme support
* 📱 Responsive and user-friendly interface

### Technology Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Django
* **Database:** MySQL
* **Authentication:** Django's built-in authentication system
* **Environment Management:** django-environ

TaskFlow is being developed incrementally, starting with the landing page and gradually integrating authentication, database models, task management, and other productivity features.
